# 把原版的学习记录带到新版

这项功能适用于已经有人在自己电脑上使用原版的情况。原版程序和原来的浏览器记录均保留，新版导入时默认合并。

## 在原使用者的设备上导出

1. 用原来那台电脑、原来使用的浏览器打开原版系统。
2. 进入 **整合报告**，点击 **全部数据(JSON)**。
3. 保存生成的 **全部考试数据_日期.json**。把这个文件传到准备使用新版的电脑或手机上。

只复制原版 HTML 程序文件不能迁移学习记录：记录存在原使用者的浏览器中。若换浏览器后看不到记录，请回到原来使用的浏览器导出。

## 在新版中导入

1. 打开新版，进入 **使用设置 → 从原版迁移数据**。
2. 点击 **选择原版导出的 JSON**，选择上一步的文件。
3. 核对预览里的考试数、题目数、新增和重复数量，再点 **确认合并原版数据**。
4. 如出现“核对旧版知识点”，根据题目选择对应知识点。暂时无法确认可以关闭，之后从使用设置继续核对。

如果刚开始使用新版，先填写学生档案和当前学习进度。旧版考试不会替你推断未记录的个人档案。

## 会保留哪些内容

- 考试名称、日期、题号、题干、对错、答案、原知识点标签、原版解析。
- 原来没有保存的题干、学生答案、解题过程和照片不会凭空补齐；界面会提示未记录。
- 原版解析单独保存，不当作学生自己的解题过程。
- 能准确匹配的知识点自动转换；较宽泛的旧标签保留原文，等待人工选择。
- 新版已有的档案、诊断和复测进展不会被原版导入覆盖。

相同内容再次导入会跳过。同一个考试编号但内容不同，会同时保留，并在导入版本的名称后注明“导入版本”，请对照后使用。

## 其他文件与恢复

也支持原版错题集 JSON、单份试卷 JSON 和原版数据库结构。错题集不包含正确题，会明确标为“仅错题”，不能把它当作完整试卷的答对率；优先使用全部数据导出。

**新版完整 JSON 备份**用于恢复整个学习空间，和原版合并不同：预览会明确提示替换。导入前可以先导出当前备份，也可使用“恢复上次导入前的数据”。该恢复副本仅保留最近一次导入前的记录，不能代替长期备份。

手机与电脑的数据分别保存在各自浏览器中。导出和导入可以转移记录，不会自动双向同步。

# 知因 · 明亮动效版

本版采用用户选定的“明亮活力”方向：清透蓝、暖黄、珊瑚橙和薄荷绿，统一首页、学习空间、知识点弹窗、表单与手机导航的视觉。

- 首页重新组织为学习目标、可重播的错题推演、三个学习步骤和原版数据导入。
- 数学与物理分别展示不等式、加速度推演，保留“示例”和“初步判断”的说明。
- 页面入场、错题卡片、提示贴纸、引导线、按钮反馈、弹窗有有限时长的动画；系统开启减少动态效果时关闭动画。
- 新主题、应用图标和离线资源清单一起更新，无新增第三方依赖、远程字体或图像请求。
- 现有知识点、详细考点说明、题目、证据判断及两个学科的独立存储保持原有机制。

## 使用

运行根目录的 `启动系统.cmd`，按窗口提示打开 `http://localhost:8765/`。使用旧档案时保持原浏览器、主机名和端口。离线版本更新会等旧页面关闭后激活；如仍看到旧界面，请关闭所有此应用的页面再打开，不要清除浏览器数据。

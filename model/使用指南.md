# 知因 · 数学与物理学习诊断

本版支持高中数学和安徽人教版高中物理。数学保留413个高中点与6个初中回溯点；物理新增443个细分点。右上角“学科”切换独立学习空间。

## 在这台电脑上打开

1. 保持交付目录完整，双击 **启动系统.cmd**。
2. 在浏览器打开 **http://localhost:8765/**。使用固定浏览器和这个固定地址，才能一直读到同一份本机记录。
3. 第一次可以点“先体验一份示例”。示例数据与自己的数据分开保存，退出示例即可返回个人空间。
4. 在“使用设置”中点“准备 / 检查离线资源”。显示“资源已就绪”后，可在同一浏览器、同一地址离线使用。

启动器使用 Node.js。当前工作环境已存在 Node.js，不会替你安装其他软件。若以后换电脑，需要先安装 Node.js，或将网页放在合适的静态网站环境中。**不要只复制 index.html，也不要以双击 HTML 的方式使用离线识别。**

## 手机上使用

页面已按手机布局适配。学生数据仍保存在使用它的那个浏览器里。

- 在家庭局域网临时使用：双击 **手机同网使用.cmd**（或运行 `启动系统.cmd --lan`），手机访问启动窗口给出的局域网地址。手机与电脑须处于同一网络，电脑服务保持运行；普通 HTTP 下可以使用网页和本机识别，但不具备手机离线重开缓存能力。
- **手机在没有电脑、没有网络时独立使用**：需将完整目录部署到受信任的 HTTPS 静态网站，在手机上打开并准备离线资源，然后按浏览器入口添加到主屏幕。本次交付没有向互联网发布网站，也没有配置公开地址。
- 本次验证的是浏览器手机尺寸布局，未在实体手机上验证摄像头、安装入口或操作系统清理缓存行为。

## 界面更新

当前为 2.1 界面版。手机右上角的调节图标可打开使用设置；今日任务中的“教材位置与完成标准”可点开阅读。离线模式下联网配置默认收起，选择联网模式会展开。已有离线缓存的用户，请在服务运行时刷新并重新准备离线资源。

## 一次考试怎么用

1. **建立档案**：年级、省份、教材版本、已学内容；填入手边教辅的名称和目录。可拍照提取目录文字，保存前核对。
2. **录入试卷**：拍照、连续添加多页，或直接粘贴文字；答案卡和大题过程可以另外上传。识别不代表已经批改。
3. **逐题核对**：校正题干、公式、标准答案、学生答案；人工标记对错。答对还可以选“确定会／不太确定／猜的”。知识点标签须确认，可以选择多个，无法分类时明确标记待确认。
4. **找原因**：将相似错题或存疑正确题合并，按 15 分钟预算追问。必要时做诊断小题。时间不够，先保存初步判断；“下一轮未诊断题”可接着处理剩余问题。
5. **照计划去学习**：根据当天可用时间安排教材与教辅中的复习和练习。平时跟课程，考试前 21 天内优先已确认的考试范围，并穿插有薄弱证据的前置基础。
6. **补后复测**：做系统检测题，或者上传对应教辅的新题作答与批改结果。第一次独立通过只记“初步掌握”；默认至少 3 天后的不同题再次通过才记“较稳定掌握”。

## 两种模式

**离线规则模式**不需要 API Key。OCR 资源已随包提供，约 33.23 MiB。图片在本机识别，但数学公式与手写过程仍可能识别错，必须对照原图修正。离线题库有严格对口题和模块基础抽查题：模块抽查仅保存证据，不会据此升级整个原子知识点。暂无对口题时可用外部教辅练习完成复测。

**联网 AI 模式**在设置中填写完整兼容接口、视觉模型名称与密钥。可以识别图片、补充追问和生成针对题。只向你配置的服务发送本次相关图片或题目；密钥仅留在当前页面内存，刷新后重新填写，备份和报告不包含密钥。服务需支持浏览器跨域请求。当前没有真实服务凭据，因此本次仅验证请求协议与失败处理，没有声称真实服务已联调成功。

## 家长报告与备份

- 家长报告默认展示困难、下一步和具体进展，可展开查看题目、学生自述与诊断依据。
- “导出报告”生成一个可以独立打开的 HTML 报告。家长不需要安装诊断系统。也可以在浏览器中打印为 PDF。
- “导出完整 JSON 备份”包含档案、原始题目、原图、诊断和复测。导入前有预览，并保留导入前的记录恢复副本。
- 原版使用者先在原来的浏览器打开原版，进入“整合报告 → 全部数据(JSON)”导出；新版进入“使用设置 → 从原版迁移数据”选择文件。默认合并并跳过重复，保留原标签和解析。详见同目录《原版数据迁移指南》。旧版没有记录的作答确定程度按存疑处理。
- 记录随浏览器和站点地址保存。换设备、换浏览器、换端口或清理网站数据不会自动同步，先导出备份。

## 如何理解诊断

这是一个可以修正的学习诊断工具。原始答对率是表现记录，不是精确的能力概率。没有检测过不等于不会，还没有学过的内容不进入薄弱判断。初步错因是教学假设，后续作答可以推翻它。

当前没有真实学生试卷与访谈样本。本版可以验证流程和规则是否按约定工作，**不能据此声称错因判断的真实准确率达到某个百分比**。

原版文件仍保留在原工作区，本版未覆盖原版 HTML、CSV 或指南。


## 高考复习与学科切换

在“能力记录”选“全部知识点”，再按册别或高考专题筛选。点击“查看”可看目标、前置基础、训练建议和易错自查；“高考分析与来源”说明所用年份及证据范围。数学参考2024—2026全国卷评析；物理参考本地教师对2024—2025安徽卷的回顾，不提供考点命中率。

两个学科分别保存备份和内容包。旧版无学科标识的备份归数学；异科学科备份会拒绝导入。换设备请分别导出两份备份，并保留原来的浏览器入口。

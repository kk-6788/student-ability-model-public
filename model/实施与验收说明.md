# 数学能力诊断优化版：实施与验收说明

用户已确认完整需求并授权执行（2026-09-08）。2026-09-09 确认增加原版数据迁移，并取消 EXE，保留手机优先网页版。本文件记录实施边界，不引入新的审批。

## 目标
单学生、家庭使用，手机优先。完成试卷录入 → 基于证据找错因 → 教材与教辅学习安排 → 即时及延迟复测 → 能力记录及家长报告。联网 AI 与离线规则两种模式共用本地数据。

## 设计
- 保留旧系统原文件，新版在独立交付目录中实现，支持导入旧版考试 JSON。
- 原子知识点沿用提供的精细知识表，保留来源、认知层级和前置关系；教材不匹配时作为通用知识分类，不虚构教材页码。
- 诊断以错题及答对但存疑题为对象，按知识点合并，预算 10～15 分钟。追问、自述与诊断小题形成证据，初步判断与证据较充分的判断区分。
- 未学习、未检测、待加强、待确认、初步掌握、较稳定掌握明确区分。原答对率作为表现数据保留，不冒充已验证的能力概率。
- 即时复测通过仅初步掌握；默认至少 3 天后的不同题复测通过才转为较稳定掌握。后续失败会降级并重新安排。
- 学生填写年级、省份、教材、进度、教辅与可用时间。根据近期材料建议进度，须确认；考前按日期和范围安排。
- 学习在外部教材与教辅完成；系统给章节/题型/完成标准，不编造页码和题号。支持系统新题和上传外部练习两种复测。
- 离线 OCR 使用本地识别资源，对照照片校正；联网模式显式配置端点和模型，密钥不进入导出。联网失败提示并允许切回离线。
- 学生和家长共享本机记录，无账户服务器和跨设备同步；导出完整可阅读报告与 JSON 备份。

## 模块与接口
- `model.js`：纯函数诊断、排序、复测状态和迁移；同时支持浏览器 `window.Model` 和 Node require。
- `migration.js`：原版导出格式识别、合并去重和迁移预览。
- `knowledge.js`：由原 CSV 转换的知识节点，浏览器 `window.KNOWLEDGE`。
- `services.js`：浏览器 `window.Services`，联网请求、本地 OCR 和缓存管理。
- `app.js` / `style.css` / `index.html`：手机与桌面操作、存储、报告。
- `server.cjs` / `启动系统.cmd`：本地静态服务；`sw.js` 支持安全来源下的离线缓存。

## 验收限制
没有真实学生样本，无法声称错因诊断准确率已达到某一百分比。题库覆盖范围、联网 API 的实际联调状态、移动设备安装条件必须如实记录。示例数据与真实数据分开使用，未经配置不发起 AI 请求。

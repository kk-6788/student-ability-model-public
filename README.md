# 学生能力模型

当前版本保留海报式构图与高中案例，右上角可选灰绿、雾蓝、浅藤、藕粉、沙杏、石墨六组柔和主题，即时预览并记住选择。详见 [多主题版说明](model/多主题版说明-20260926.md)。本轮 103 项 Node 测试、18 项浏览器检查通过。

这是知因数学与物理学习诊断模型的独立交付仓库。

2026-09-26 更新：保留 419 个数学知识点和原有 443 道题，新增安徽人教版高中物理六册、27章、125节的 443 个细分知识点。右上角切换学科；数学、物理档案与试卷分别保存，旧数学备份仍可使用。

数学新增依据2024—2026全国卷评析整理的复习专题、练习建议和易错自查；物理参考安徽本地教师对2024—2025试卷的分析。可按册别、专题筛选、分页查看；来源和适用边界见 [教材与高考分析说明](./model/物理教材与来源核查.md)。不提供无逐题依据的频次、分值占比或命中率。

物理当前为知识目录与诊断流程接入，未附带正式核验题库。复测可上传教辅新题及人工核对记录；未审核题目、AI草稿不能改变掌握状态。

可运行源码与数据位于 [model/](./model/) 目录，进入该目录后运行 `启动系统.cmd`；也可直接打开 `index.html`。核心内容包、知识点核验清单和题目核验页面均已纳入仓库。

推荐本地服务器方式打开，以支持缓存和稳定的浏览器存储来源。仓库不包含体积较大的 OCR vendor 文件；完整本地交付包保留这些资源。不要改变原来的主机名、端口或浏览器来寻找旧记录；更换入口前先分别导出两个学科的完整备份。

验证：在 `model` 目录运行 `node --test`。物理目录由 `build_physics.py` 生成；高考专题位于 `exam-focus.js`，修改后运行 `node export-exam-map.cjs` 刷新 JSON/CSV 映射。

能力模型区分知识理解、独立完成、题型迁移和保持稳定；多步骤题需人工对照过程，不以答案字符串自动判分。

本项目没有真实学生样本效度验证，不能作为心理或智力测评。

考点详情新增核心概念、公式关系、适用条件、解题步骤、易错点与本节清单。物理提供27章共享讲解和27个章节示例，数学结合19组章节讲解与当前知识点的内置例题。点击看过解答的数学例题不再作为新题复测；该记录随备份保存。两科JSON/CSV复习映射同时包含这些学习内容，章节示例不冒充逐点核验题。
